# مجتمع المواهب — منصة تسجيل المرشحين مع فرز بالذكاء الاصطناعي

مشروع Next.js + Supabase + Claude API لاستقبال طلبات المرشحين (توظيف / إعارة)،
تحليل سيرهم الذاتية تلقائياً، وعرضها في لوحة تحكم مرتبة حسب الأنسب.

## 1) تثبيت المشروع محلياً

```bash
npm install
```

## 2) إنشاء مشروع Supabase (مجاني)

1. سجّل في https://supabase.com وأنشئ مشروعاً جديداً.
2. من **SQL Editor** داخل المشروع، افتح ملف `supabase-schema.sql` الموجود هنا،
   انسخ محتواه بالكامل، والصقه وشغّله (Run). هذا سينشئ جدول المرشحين وصلاحيات الوصول
   وحاوية تخزين ملفات السير الذاتية باسم `cvs`.
3. من **Authentication > Users** أضف مستخدم واحد يدوياً (بريد وكلمة مرور) لتكون
   هذه بيانات دخول الأخصائية للوحة التحكم.
4. من **Project Settings > API** انسخ:
   - `Project URL`
   - `anon public key`
   - `service_role key` (سري جداً، لا تشاركه أو تضعه في الفرونت إند)

## 3) إعداد Claude API

1. افتح https://console.anthropic.com وأنشئ مفتاح API.
2. انسخ المفتاح (يبدأ بـ `sk-ant-...`).

## 4) متغيرات البيئة

انسخ الملف `.env.local.example` باسم `.env.local` واملأ القيم التي جمعتها في
الخطوتين السابقتين.

```bash
cp .env.local.example .env.local
```

## 5) تشغيل المشروع محلياً

```bash
npm run dev
```

افتح المتصفح على:
- `http://localhost:3000` → الصفحة الرئيسية
- `http://localhost:3000/apply` → فورم التقديم
- `http://localhost:3000/admin/login` → دخول الأخصائية للوحة التحكم

## 6) النشر على الإنترنت (مجاني)

أسهل طريقة هي **Vercel**:

1. ارفع المشروع على GitHub (repo جديد).
2. سجّل في https://vercel.com واربطه بحساب GitHub.
3. اختر الـ repo واضغط Import.
4. أثناء الإعداد، أضف نفس متغيرات البيئة الموجودة في `.env.local` من خلال
   قسم **Environment Variables** في Vercel.
5. اضغط Deploy، وستحصل على رابط عام مثل:
   `https://talent-community.vercel.app`

## هيكل المشروع

```
app/
  page.tsx                 → الصفحة الرئيسية
  apply/                   → فورم التقديم (3 خطوات)
  apply/thank-you/         → صفحة تأكيد التسجيل
  admin/login/             → دخول الأخصائية
  admin/                   → لوحة التحكم (عرض وترتيب المرشحين)
  api/analyze-cv/          → تحليل السيرة الذاتية عبر Claude API
lib/
  supabaseClient.ts        → عميل Supabase (للمتصفح)
  supabaseServer.ts        → عميل Supabase (للسيرفر فقط - صلاحيات كاملة)
  formOptions.ts           → قوائم اختيار الفورم
supabase-schema.sql        → إعداد قاعدة البيانات والتخزين
```

## ملاحظات مهمة

- درجة الفرز (`ai_score`) تُحسب تلقائياً بعد كل تقديم، وتعتمد على تحليل
  Claude لسنوات الخبرة والمؤهلات العامة الموجودة في نص السيرة الذاتية.
- التحليل يحدث في الخلفية (لا يؤخر ظهور شاشة "تم التسجيل بنجاح" للمرشح).
- لتغيير طريقة التقييم (مثلاً مقارنة بوظيفة محددة بدل معايير عامة)، عدّل
  نص الـ prompt داخل `app/api/analyze-cv/route.ts`.
